# TODOPOP 0.3.0 实施与复核报告

日期：2026-10-23。依据用户提供的设计师 ZIP 与后续反馈进行适配。

## 本次结果

- Dock 已恢复 plain 白色椭圆，移除字标轮廓贴纸。保留拖动、键盘箭头微调、位置记忆；展开/收起面板不跳回原位。
- Blow a bubble：四档可拖滑杆、行内分组增删改、分组位置、可展开的可选 Link。
- Tint & Group：移植原型的动态色环、饱和度和 OKLCH 分组色算法；预设组色跟随 Tint，自定义组色独立。色盘没有可被原生拖出的图片。
- 分组靠边与全局靠边分开保存。全局覆盖所有组、未分组和新增任务；切回 By group 恢复组侧边设置。
- Squish：40 点弹簧膜、相邻点耦合、接触约束、局部鼠标扰动与平滑曲线；内圈、命中和面积计算跟随轮廓。
- 保留单击 URL/billboard、双击编辑、右键 Pop、撤销、教程与 95% 停长；没有恢复 Pause Growing 或泡泡底下的三按钮。

## 测试详情

完整验证共 12 个阶段全部通过：类型、单元、格式、构建、扩展 UI、色盘、Dock、设计师迁移、桌面验收、巨泡可达性、30 泡压力、端到端集成。具体命令、退出码和耗时见 test-results/summary.json；逐项输出保存在同目录日志。

- Dock：真实指针拖动、边界约束、键盘微调、重启恢复、展开锚点、无贴纸及椭圆样式。
- 分组：两组分居左右，全局覆盖与新任务继承，By group 恢复，重启保存。
- 配色：拖色环不拖动窗口、不产生图片拖放；颜色有效、浅纸底；自定义组色不随 Tint 改变。
- 交互：单击/双击不串触发、独立本地 billboard、Pop 粒子与撤销、历史和草稿持久化。
- 原生压力：30 个气泡窗口均可加载，Focus 隐藏/返回恢复，无 renderer 错误。最近一次 snapshot 调用约 62–128ms；此项验证正确性，不等于长时间动画帧率达标。

## 实现边界

保留当前独立气泡窗口架构，移植膜算法与视觉参数，没有直接替换为原型的单窗口 Canvas。中心排列仍由当前布局器管理，局部漂浮有界；因此手感应实机复核，不能视为完全复刻原型的整体物理轨迹。

95% 使用可见轮廓联合覆盖近似计算：曲线离散为 80 点，覆盖结果有约 250ms 缓存。正式增长仍沿用 Now 2 分钟、Today 4 分钟、Soon 8 分钟约增加一个逻辑厘米，Remind 不长；没有复制原型不同的增长文案。原有任务与 HEX 自定义颜色保持兼容，没有导入演示任务或完成记录。
