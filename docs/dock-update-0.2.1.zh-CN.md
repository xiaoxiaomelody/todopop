# TODOPOP 0.2.1 · 可移动 Dock

按最新反馈调整了 Dock：收起时从 376px 缩到 300px，减少上下留白，去掉帮助与连接状态外的大圆框，保留 Logo 与三个 O 的入口。

![新版 Dock](screenshots/movable-dock.png)

拖动左侧小柄，或 Logo 周围的标题空白区域，就能移动。三个 O、帮助与连接按钮仍是点击操作，不会顺带拖动。拖动柄获得键盘焦点后，也可以用方向键微调。

位置在松手后保存，重启恢复。展开面板时保留位置；如果展开后会越出屏幕，则临时夹紧到工作区，收起后回到保存的停靠点。拖出屏幕边缘也会被限制在可用工作区内。

同时去掉了已选分组开始拖动前的不必要异步等待，避免快速拖动手势丢失。

本轮验证：类型检查、生产构建、25 项逻辑测试、Dock 专项和桌面主流程回归。Dock 专项涵盖实际鼠标拖动、键盘微调、保存/重启、展开收起和屏幕边界；结果见 [dock-ui-result.json](dock-ui-result.json)。本轮没有重跑 Chrome 集成或 30 泡负载；它们的上一次完整结果属于 0.2.0。
