# 气泡操作与扩展连接窗口修订

日期：2026-10-23。

气泡的底部操作区以前随整个 SVG 一起缩放，超大气泡可能把按钮放到工作区外。现在操作按钮固定为 32px，随原生气泡窗口的位置和尺寸更新，限制在当前显示器工作区内。保留气泡有链接时点击打开、无链接时点击 Pop 的规则；✓ 始终直接完成。若旧版暂时点不到，先打开 Panel → Floating，点击该任务右边的 Pop 图标。

Chrome 扩展改为点击工具栏图标打开独立连接窗口，重复点击聚焦已有窗口。取消原先方框内再套一层圆角卡片的布局，删去标语、介绍段落、重复连接说明和隐私页脚。未连接时以配对码输入和 Connect 为主；连接后只保留状态、自动 Focus 提示及更换/断开操作。窗口按内容自动调整高度。继续使用 Unbounded 和共享按钮、输入框、主题。

独立 Chrome 窗口仍有浏览器/系统边框，不能提供 Electron 的透明无框窗口。没有增加权限。配对窗口本身不算匹配任务网页。
