# TODOPOP 当前产品规则

**0.2.1 后续修订：Dock 改为可移动。收起时 300px 宽，帮助与连接去掉大圆框；拖动柄或标题空白区域可移动，保存位置，展开/收起保留位置。此规则覆盖旧方案中的固定位置要求。**

当前实施版本为 0.2.0；已执行的功能、测试与剩余人工复核见 [0.2.0 实施报告](implementation-report-0.2.zh-CN.md)。下方保留历次确认，冲突时以最新确认和当前实施报告为准。

## 已确认的实施口径（后续确认，优先于下文历史评估）

- 字标的三个 O 分别打开独立内容：第一个 **Blow a bubble**，第二个查看已完成的 bubble，第三个 **Tint & Group**。不采用“第三个 O 同时打开三块”的旧假设。
- Squish 参考用户提供的两泡接触截图及原始 Figma：接触位置产生局部凹陷、挤压和不对称轮廓，保留内外描边层次；文字不随轮廓被拉扁。静态截图作为形态参考，动态参数需要开发时验证，不声称截图已定义完整物理模型。
- 普通单击可以短暂延迟，以区分双击；单击有 URL 时打开 URL，无 URL 时进入 billboard。双击只进入编辑，不先触发单击动作。右键 Pop，移除气泡下方三个按钮及打勾设计。
- Description 指编辑现有任务名称、URL、紧急程度与分组，不新增独立备注字段。
- 95% 采用此前建议：全部可见气泡在桌面可用工作区内的联合覆盖面积占比；重叠计一次、屏外裁去，排除菜单栏和 Dock。计算以气泡实际外轮廓为边界，内部装饰线不重复计数，不计透明窗口空白、阴影、控制条和面板。达到 95% 时全部停止增长，Pop 后面积低于阈值再恢复。实现时应验证变形轮廓和面积估算精度，不能继续沿用圆面积直接求和。
- Pop 视觉效果和环形调色器以原始 Figma 为准；新增/已完成/Tint & Group 的教程配合单击、双击、右键及 billboard 返回一并制作。

以上是已确认需求，尚不代表本轮已实现。正式增长速率与 billboard 视觉范围可继续按方案建议推进，不能把旧文中的已解决问题继续当成阻塞项。

日期：2026-10-23。本文记录用户最新确认，优先于旧 Figma 审查文档中的待决策项。

## 后续反馈修订：点击、Pop、配色与增长

以下是用户对本方案的新反馈，优先于下文原建议；此处记录需求，尚未修改应用或完成动效验收。

- 普通点击气泡：有 URL 打开 URL；无 URL 进入本地 billboard。
- 右键气泡：Pop。替代旧版右键编辑和方案中的 ✓ 完成入口。
- 双击气泡：进入/编辑 bubble description；编辑字段范围待确认。
- 移除每颗气泡底下的 Snooze、编辑、✓ 三个按钮，不保留打勾式 Pop 设计。
- Pop 需要伴随原始 Figma 设计中的视觉动效；开发时核对对应动效，不能只删除窗口或沿用未核对的简化效果。
- 配色使用原始 Figma 的环形调色器，取代当前原生色选框/色块排列；配色能力仍包括分组颜色与饱和度。
- 气泡覆盖屏幕面积达到 95% 时停止增长。面积采用单泡还是全部气泡、重叠和屏外部分如何计入，待用户确认；原来的 76% 圆面积估算不满足这条要求。
- 加入首次使用教程，并保留可重新打开的帮助：普通点击、双击编辑、右键 Pop、billboard 返回。教程用临时示例气泡，避免误完成真实任务。

待确认：单击与双击的时间冲突；95% 的面积定义；description 是否包括独立的自由文本备注。右键 Pop 应立即提供反馈，动画结束后移除窗口；完成应可撤销。教程并不能替代触控板/辅助输入的等价入口，后续可在任务列表保留文字操作，不重新给气泡挂三个按钮。

以下为此前规则记录；与上述新反馈冲突的点击、右键、✓、配色和增长阈值条目已被替代。

- 气泡本身也按链接区分：有 affiliated URL，点击打开 URL；没有 URL，点击直接 Pop。右键仍编辑。音效暂不做。
- 编辑层主操作同样按链接区分：有 URL 打开；无 URL 完成。
- 保持自动 URL Focus：Chrome 前台 URL 匹配就隐藏气泡；离开匹配页面/前台就恢复。不做手动会话优先级和退出抑制。
- Step、Focus 计时条从当前范围移除；不为它们建立窗口或编辑流程。归档仍可累计自动专注的历史时长。
- 增长分正式速度与 Demo 预览。正式模式以逻辑 1 cm≈37.8 px、最高紧急级别每 2 分钟增加 1 cm 为基准；较低级别更慢，提醒级保持小。不是对真实显示器物理厘米的保证。
- Demo 使用独立临时时钟，默认 60×，不把预览增长写回正式等待时长；退出 Demo 恢复正式尺寸。它用来检查 Fill-up，不把原型每 1.6 秒切换画面当成生产规则。
- 用户暂停、自动 Focus、Screen full、单任务 Snooze 都停止对应增长。正式程序未运行或系统睡眠期间不补算增长；恢复时不突然追长。
- 全局暂停保持气泡可见并显示暂停样式；与单任务隐藏 10 分钟的 Snooze 区分。支持 30 min、1 hour、Till tomorrow、Until I resume。
- Rebubble 创建新的任务 ID/新一轮，重置等待与增长，保留过去完成事件；不抹掉旧完成记录。
- 分组使用稳定 ID，名称可编辑，配色与 urgency 分开。默认仍为 School / Work / Life；新增、改名、移除和侧边位置按计划补齐。
- UI 初始仍用现有蓝色方案；正文与控件采用 Unbounded，Logo 保留现有 Unbounded 字形。主题与组色设置不改变初始默认外观。
- 手机端不做；不增加用户账号、任务云同步。桌面版维持本地运行。
- 优先完成 Chrome Extension UI，再按数据/历史 → 增长/暂停 → 布局 → 分组/主题/排序 → 归档/撤销/Launcher → 打包与验收继续。
- 遇到需要发布凭据、外部审核或暂时无法验证的环节，先记录并跳过，最后提供进度报告、测试详情和人工复核清单。

- 字体后续修订：按用户截图恢复 Unbounded，扩展和 Panel 的正文、按钮、输入框共同使用；保留输入框无矩形 focus 框的设置。

- 交互后续修订：气泡操作按钮固定 32px 并保持在可见工作区内；扩展使用独立连接窗口，界面只保留配对与状态等必要操作。
