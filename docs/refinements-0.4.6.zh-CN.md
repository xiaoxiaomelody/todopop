# TODOPOP 0.4.6

- 保留透明分组填色，增加膜面反射、上缘高光和柔和亮边，参考透明肥皂泡图片。
- 在紧急程度下显示「色点＋Group 名称」；分组任务用名称标签代替日期行，避免文字越来越多；未分组保留日期。
- Pop 播放用户提供的 universfield-bubble-pop-08-351339.mp3，音量 60%。由主窗口集中播放，只有任务首次实际完成时触发；删除、撤销和重复完成请求不播放。教程示例也播放同一声音。
- 移除 Clear group selection 提示条；创建或编辑任务时选组只改变该任务，不调用桌面高亮，也不淡化其他气泡。
- 移除 Group 的位置选择控件。上下左右、自由漂浮与 Shuffle 全部应用于所有气泡，旧的分组方向和位置锁定不再参与布局。
- Dock 与备用入口改为 macOS panel 类型，保留跨 Space／全屏置顶设置。Focus 只隐藏气泡，Dock 不再被 URL Focus 隐藏。依据 [Electron 面板窗口说明](https://www.electronjs.org/docs/latest/api/base-window)。实际跨应用行为仍需人工确认。
- 问号按钮的悬停提示包含版本号，方便确认正在运行新版。

安装：完全退出旧 TODOPOP，再从 DMG 替换 Applications 里的应用后重新打开；打开 DMG 本身不会更新正在运行的版本。

按用户要求，本轮只修改、构建和打包，不运行测试。跨全屏显示、音效播放与立体观感请安装后人工复核。安装包仍为未公证的本地预览。
