# TODOPOP 0.2.2 · 修复色环拖拽与黑色泡泡

色环是一张图片，旧实现没有阻止 HTML 原生图片拖拽，因此拖动选色时可能出现“把色盘拎出来”的影像。现在图片明确不可拖拽，鼠标事件交给色环本身处理；键盘选色和 HEX 输入仍可用。

黑色泡泡来自颜色格式错误：改变 Tint 后，预设组色返回 HSL 字符串，旧代码却直接追加 HEX 透明度后缀，导致 SVG 颜色无效，回退成黑色。现在组色统一返回合法 HEX，泡泡的填充颜色与透明度分开设置。分组色环读取这些预设时也不再产生 NaN。

同时将分组拖动的开始消息绑定到具体组 ID，避免快速操作在异步选中过程中丢失拖动起点。

新增测试覆盖实际拖动色环、原生图片拖拽事件计数、Dock 不移动，以及接近原蓝的新 Tint、Berry、Teal、Graphite 下泡泡的真实 SVG 填充。逻辑测试遍历每个主题的六个预设组色，验证颜色与 HSV 转换都有效。结果见 [颜色界面专项](color-picker-ui-result.json)；桌面主流程继续回归。

没有修改用户的真实任务和颜色设置。新版会按原先保存的颜色正常渲染，不需要清空或重建气泡。
