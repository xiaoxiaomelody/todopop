# TODOPOP 0.4.1：测试反馈修复

日期：2026-10-23。

## 修复内容

**增长跳位与轮廓闪动。** 以前每次读取状态都运行碰撞排布并改写位置，空间不足时会重复寻找不同解；侧边队列还可能被碰撞后的坐标重新排序。本版相同布局输入复用同一结果，队列沿用已有顺序，并限制增长时中心位置的单步调整。手动排列仍可重新排布，重置布局放在规则保存完成之后，避免异步保存期间又缓存旧规则。Shuffle 也会使旧缓存失效。

同时，React 更新不再把正在运行的膜轮廓和点击区域重置为静态多边形；动态曲线由膜动画持续维护。单击与长按也不会再把自动排布位置误写成手动拖动位置。保留小幅漂浮、接触变形与长按蓄力。新增窗口、切换排列、切换 Real/Demo 等明确操作仍会调整布局；屏幕尺寸或显示器变化也会重新布局。

**编辑窗口的 Untrusted window。** 这是内部窗口权限拒绝提示，不表示任务或 URL 不可信。编辑表单复用分组管理控件，但分组接口原先仅允许主面板调用，导致编辑窗选组时出现该错误。本版允许当前主面板和已登记编辑窗口调用分组接口，继续限制编辑窗口只能修改自己对应的任务，气泡窗口不能管理分组。没有关闭窗口来源检查。

**通知可读性。** “Clear group selection” 改为白底、深色文字、描边的独立提示；错误提示也有不透明底色，Toast 与 Undo 明确使用白字，避免直接叠在壁纸上读不清。

**分组自动填色与透明度。** 按用户追加反馈，气泡直接用所属 Group 的颜色填充，移除内部色环；未分组使用当前主题色。提醒级填充不透明度为 14%，其他气泡从约 18% 起随尺寸缓慢上升，最高 28%，替代白色底。改组色会实时更新填充，自定义组色仍独立于主题色。标题和外轮廓保留，分组淡化规则保留。编辑面板本身使用不透明白底。

**Chrome connection。** 删除 “Demo only · copy this code into the extension.” 提示行，连接入口与配对码功能保留。

右键仍进入编辑；单击 URL／Focus、长按 Pop 的交互保持。

## 测试详情

专项：`node scripts/feedback-regression.mjs`，结果见 [feedback-regression-result.json](feedback-regression-result.json)。

- 实际右键打开编辑窗，选择分组、新建分组、改名、保存任务，不出现 Untrusted window。
- 编辑窗不能修改另一个任务或全局设置；气泡窗口不能调用分组修改接口。
- 通知的文字／底色对比度达到 4.5:1；分组填色位于 14–28% 区间。
- 布局条件相同的连续状态读取不移动气泡；拥挤 60× 增长保持局部位移，无大幅跳转。
- 共享逻辑测试模拟拥挤自由布局、靠左和靠右布局，各持续增长 180 次，检查每次中心位移。

完整回归命令、退出码与耗时见 [test-results/summary.json](test-results/summary.json)。测试使用临时任务目录，没有操作真实数据。Chrome 前台激活在本次桌面环境中不稳定，因此集成测试使用明确记录的前台 API 边界夹具；真实 macOS 应用切换仍需人工复核。
