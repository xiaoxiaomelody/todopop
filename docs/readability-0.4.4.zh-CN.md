# TODOPOP 0.4.4

- 移除 Grand Pop 的蓄力放大、文字放大和爆开扩张，恢复普通大小的十枚液滴；长按完成保留，只留轻微抖动。

- 标题最多显示三行（紧凑布局两行），完整名称保留在无障碍标签和 Focus／编辑里；文字不再跟随膜抖动和放大。
- In the bubble 恢复浅底深字，教程示例同步。
- 移除拖动手柄的蓝色 focus 椭圆框，保留移动和键盘微调。

按用户要求，本轮只修改、构建和打包，没有运行测试；晚期拥挤场景的实际观感仍需人工复核。
